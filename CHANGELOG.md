# Changelog

All notable changes to the UK Mortgage Calculator will be documented in this file.

## [1.0.0] - 2026-02-17

### Initial Release

#### Features
- 🏠 **Core Mortgage Calculator**
  - Monthly payment calculations using accurate UK formulas
  - Property price range: £50,000 - £2,000,000
  - Deposit: 5% - 50%
  - Interest rates: 1% - 8%
  - Terms: 5 - 40 years

- 💰 **Stamp Duty Calculator**
  - England and Northern Ireland (SDLT)
  - Scotland (LBTT - Land and Buildings Transaction Tax)
  - Wales (LTT - Land Transaction Tax)
  - Accurate rates as of February 2026

- 📊 **Loan to Value (LTV)**
  - Real-time LTV calculation
  - Color-coded risk indicators
    - Green: < 60% (low risk)
    - Blue: 60-80% (medium risk)
    - Orange: 80-90% (high risk)
    - Red: > 90% (very high risk)

- 📈 **Visualizations**
  - Interactive mortgage balance graph
  - Principal vs interest breakdown
  - Full amortization table
  - Monthly and yearly views
  - Smooth animations

- ⚙️ **Settings**
  - Default region preference
  - Default term preference
  - Dark mode support
  - Reset to defaults option
  - Persistent settings storage

- ✨ **User Experience**
  - Clean, professional interface
  - Real-time calculations (no calculate button needed)
  - Smooth sliders with text input
  - Works completely offline
  - No ads or tracking
  - No login required
  - Fast and responsive

#### Technical
- Built with Flutter 3.8.1
- Material 3 design system
- Comprehensive unit tests
- Optimized for performance
- Clean architecture pattern
- Minimal dependencies
